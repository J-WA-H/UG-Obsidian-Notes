Consider total angular momentum $\underline{J}$ with quantum number $J=0, \frac{1}{2}, 1,\dots$. Due to the condition that $-J\leq J_{z}\leq J$, each $J$ value has $2J+1$ states.
Total angular momentum can be given (in [[Natural Units]]) by
$$\underline{J}^2=J(J+1).$$
$\underline{J}$ consists of orbital angular momentum and spin
$$\underline{J}=\underline{L}+\underline{S}.$$
$$\lvert L-{S} \rvert\leq J\leq L+S .$$
The eigenstates of angular momentum are described by spherical harmonics
$$Y_{lm}(\theta,\phi)=Y_{lm}\left( \frac{\underline{x}}{\lvert \underline{x} \rvert } \right).$$
Applying the [parity operator](Symmetries%20and%20Parity.md) to the spherical harmonics:
$$\hat{P}Y_{lm}\left( \frac{\underline{x}}{\lvert \underline{x} \rvert } \right)=Y_{lm}\left( -\frac{\underline{x}}{\lvert \underline{x} \rvert } \right)=(-1)^{l}Y_{lm}\left( \frac{\underline{x}}{\lvert \underline{x} \rvert } \right).$$
