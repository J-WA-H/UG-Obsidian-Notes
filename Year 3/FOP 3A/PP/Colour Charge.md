When examining the structure of the $\Delta^{++}$ particle, it was found to have $uuu$ valence quarks - which is forbidden by quantum mechanics.

This particle is a baryon, so by Pauli exclusion it must have an antisymmetric wavefunction.
$$\psi_{baryon}=\psi_{spatial}\psi_{flavour}\psi_{spin}.$$
Considering the ground state, the spatial wavefunction is always symmetric.

We cannot make $\psi_{flavour}$ antisymmetric as there is no way to make $\ket{uuu}=-\ket{uuu}$, so it must be symmetric.

For the same reason, $\psi_{spin}$ must be symmetric as $\Delta^{++}$ has spin $\frac{3}{2}$ so there is no way to make the spin state antisymmetric.

As $\psi_{baryon}$ must be antisymmetric, there must be another quantum number that is only seen in strong scattering. 

Analogous to the electromagnetic charge (+) and anti-charge (-), quarks can be modelled with having 3 possible charges and 3 anti-charges.

These are colour charges - red, green, blue:
Quarks have colour $rgb$ and antiquarks have anti-colour $\bar{r}\bar{g}\bar{b}$.
$$r,g,b$$
$$\bar{r},\bar{g},\bar{b}.$$
Quarks have colour $rgb$ and antiquarks have anti-colour $\bar{r}\bar{g}\bar{b}$.

This allows for an additional term in the wavefunction, $\psi_{colour}$, which allows for an anti-symmetric combination, e.g.
$$\ket{rbg}=-\ket{bgr}.  $$
Hadrons must be white overall. For a baryon containing 3 quarks, each quark must have a different colour, $rgb$, so that it is overall white.

For mesons, we only have $q\bar{q}$ as we need an overall white particle. There is no way to make a white particle with $qq$ or $\bar{q}\bar{q}$ particles - which is why they don't exist in nature.

This requirement for white particles only allows for bound states to have 2 or 3 quarks - which also explains quark confinement.
