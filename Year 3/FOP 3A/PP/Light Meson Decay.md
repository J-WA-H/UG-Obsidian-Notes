When considering the decay of mesons, we need to consider the [conservation](Conserved%20Quantities.md) of parity and angular momentum.

Consider a bound meson
![[Pasted image 20250228103613.png]]
This has parity $P(q\bar{q})=(-1)^{L+1}$ and orbital angular momentum $L$.
If 1 has total angular momentum $J_{1}$ and 2 has total angular momentum $J_{2}$ then
$$|J_{1}-J_{2}|\leq J_{tot}\leq J_{1}+J_{2}.$$
Example: $\pi^{+}(u\bar{d})$.
By definition the $\pi^{+}$ meson is in its ground state, $1^1S_{0}$, so $n=0,L=0$.
It has parity $P(\pi^{+})=(-1)^{0+1}=-1$ so it can be [written as](Isospin%20and%20Strangeness.md) $J^{P}=0^{-}$.
For the $\pi^{-}(d\bar{u})$ - parity is independent of charge so there is no difference, $J^{P}=0^{-}$.
Now consider $\rho^{0}\left( \frac{1}{\sqrt{ 2 }}(u\bar{u}+d\bar{d}) \right)$. As this is a quantum mechanical combination - pick one state - $u\bar{u}$. 
$\rho^{0}$ is in the $1^{3}S_{1}$ state so $S=1,L=0$ so $J=1$.
The parity of $\rho^{0}$ is $P(\rho^{0})=(-1)^{0+1}=-1$ so $J^{P}=1^{-}$.
These can be used to check if the decay of $\rho^{0}$ into $\pi^{+}$ and $\pi^{-}$ is possible.
$$\rho^{0}\to \pi^{+}+\pi^{-}$$
$$1^{-}\to 0^{-}+0^{-}.$$
The parity before is $-1$ and the parity after us $(-1)(-1)(-1)^{L_{after}}=(-1)^{L_{after}}$. There is the additional term to allow for any angular momentum of the two pions orbiting each other.
For parity to be conserved, $(-1)^{L_{after}}=-1$ so $L_{after}$ must be odd.
To find $L_{after}$, consider conservation of angular momentum. Before has angular momentum 1 and after has angular momentum $L_{after}$, so $L_{after}=1$.

This gives a route than conserves parity and angular momentum.
![[Pasted image 20250228135948.png]]
This decay is possible only if the pions orbit each other with angular momentum $L=1$ - in the P state.

Given, by definition, $\pi^{0}$ is in its ground state so $J=0$ but as the photon has spin 1, it has $J=1$ so angular momentum is not conserved so this decay cannot happen.

In this decay, the same issue occurs, with $\pi^{+}$ having $J=0$ and $W^{+}$ having $J=1$. However, due to the mass of the $W^+$ boson, it doesn't travel at the speed of light like gluons and photons so it experiences time and spatial dimensions which means angular momentum doesn't have to be conserved, so this decay is allowed.
