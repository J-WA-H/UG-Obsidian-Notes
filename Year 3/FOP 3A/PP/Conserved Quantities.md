Throughout a particle interaction, charge, lepton number, and baryon number must be conserved.
Lepton number defines the number of leptons - leptons have a lepton number of +1 and anti-leptons have a lepton number -1.

Baryon number defines the number of baryons - quarks have a baryon number of $+\frac{1}{3}$ and anti-quarks have a baryon number of $-\frac{1}{3}$.

Example: consider the [[Beta decay]] of a neutron (udd) int a proton (uud), draw the [diagram](Feynman%20Diagrams.md):
$$udd\to uud+e^{-}$$
As both the neutron and the proton have one up and one down quark, they remain unaffected. This means we only need to consider a down quark decaying into an up quark and an electron.
$d$ and $e^{-}$ differ in charge by $\frac{2}{3}$, but there is no force mediator with this charge so this interaction doesn't happen.
$d,u$ differ in charge by $1$, so the force mediator must be a $W$ boson.
This must be a $W^{-}$ boson to conserve charge in the middle of the decay.
This $W^{-}$ boson produces an electron - but there must be another line to complete the vertex.
As the end has an electron, there is a lepton number of +1, but at the beginning there is a lepton number of 0, so there must be an extra particle produced by the $W^{-}$ boson with lepton number of $-1$. To preserve the lepton number in the generation, this must be an anti-electron neutrino.

There are two other conserved quantities, parity and angular momentum.

Parity defines whether a wavefunction is invariant under a reflection.
![[Pasted image 20250214101455.png]]
Considering a $q\bar{q}$ meson, if one has positive parity, the anti-particle has negative parity and vis versa.

The parity of a meson is given by
$$P(q\bar{q})=P(q)P(\bar{q})=-1.$$
A bound pair also has angular momentum $L$.
![[Pasted image 20250214101738.png]]
$\hbar$ quantises angular momentum - which are integer multiples of $\hbar$. 

| L      | 0   | 1   | 2   | 3   |
| ------ | --- | --- | --- | --- |
| letter | S   | P   | D   | F   |
The spherical harmonics $Y_{\ell m}(\theta,\phi)$ which define angular momentum eigenvalues are the same for mesons and atoms.

$L$ defines the parity of the meson

| L   | 0   | 1   | 2   | 3   |
| --- | --- | --- | --- | --- |
| P   | +   | -   | +   | -   |
This can be used to update the parity of a meson.
$$P(q\bar{q})=P(q)P(\bar{q})(-1)^{L}.$$
