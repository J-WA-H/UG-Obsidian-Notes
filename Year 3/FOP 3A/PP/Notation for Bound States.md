Bound states of quarks are given by 4 quantum numbers:
- $n$ - principal quantum number (defined $n^{th}$ radial wavefunction)
- $S$ - Spin ($\uparrow$ or $\downarrow$, $+\frac{1}{2}$ or $-\frac{1}{2}$).
- $L$ - orbital [angular momentum](Conserved%20Quantities.md), given as a letter.
- $J$ - total angular momentum

The notation used to describe a quark state is
$$n^{2S+1}L_{J}.$$
For example consider a $c\bar{c}$ meson with spin $\uparrow\downarrow$, $S=0$, in its ground state so $n=1$ and $L=0$, so it has total angular momentum $J=0$. This is given by
$$1^{1}S_{0}.$$
If this state is excited to spin $\uparrow\uparrow$, $S=1$, $\implies J=1$ so this state is then described by
$$1^{3}S_{1}.$$
