#### Von-Neumen axioms
- In QM every observable is represented by a Hermitian operator
- QM state of a system is represented by a state vector $\psi(x)$
- When we measure a quantity $Q$ in state $\psi$ many times is measuring many copies of this system.

#### Hydrogen atom
$$\hat{H}=-\frac{\hbar^2}{2m}\nabla^2+V(r)$$
$$\hat{T}=\frac{1}{2m}\left[ -\hbar^2 \frac{\partial}{\partial r}\left( r^2 \frac{\partial}{\partial r} \right) +\hat{L}^2 \right]$$
The kinetic energy operator contains the $\hat{L}^2$ operator that has eigenfunctions
$$\hat{L}^2Y_{lm}(\theta,\phi)=l(l+1)\hbar^2Y_{lm}(\theta,\phi)$$
$$L_{z}Y_{lm}(\theta,\phi)=m\hbar Y_{lm}(\theta,\phi).$$
The angular momentum raising/lowering operators raise/lower the magnetic quantum number
$$\hat{L}_{+}Y_{lm}(\theta,\phi)\propto Y_{lm+1}(\theta,\phi)$$
$$\hat{L}_{-}Y_{lm}(\theta,\phi)\propto Y_{lm-1}(\theta,\phi)$$
$$\text{where } \hat{L}_{+}=\hat{L}_{x}+i\hat{L}_{y}$$
$$\text{and } \hat{L}_{-}=\hat{L}_{x}-i\hat{L}_{y}.$$
