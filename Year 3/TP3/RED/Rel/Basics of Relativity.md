Consider 2 events $x^\mu$ and $y^\mu$. Take
$$S=(x-y)^2=(x-y)^\mu(x-y)_{\mu}=(x^\mu-y^\mu)(x_{\mu}-y_{\mu}).$$
Since this is a [Minkowski scalar product](Lorentz%20Group%20and%20Minkowski%20Scalar%20Product.md), it is invariant under a Lorentz transformation so all observers agree on the value of $S$.
The different values of $S$ define different types of events:
- $S=0$ light like event - two events linked by the speed of light
- $S<0$ space like event - Spatial components of the events are larger than the temporal.
- $S>0$ time like event - temporal component larger than the spatial components.

A worldline shows an events progression through spacetime.
To live in the $S<0$ region, travel faster than $c$ will have to be achieved - so our worldline must be within the $S>0$ region. Causal links are broken in this region.

We define the future as all events causally linked with an event and $t>0$, and the past as all events that occur before an event, with $t<0$.
