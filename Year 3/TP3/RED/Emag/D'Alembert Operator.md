We define the D'Alembert operator as
$$\square=\mu_{0}\varepsilon_{9} \frac{\partial^2}{\partial t^2}-\nabla^2=\frac{1}{c^2} \frac{\partial^2}{\partial t^2}-\nabla^2.$$
Using this we can rewrite the potentials in the [Lorentz gauge](Lorenz%20Gauge.md) as 
$$\square \phi=\frac{\rho}{\varepsilon_{0}}$$
$$\square \underline{A}=\mu_{0}\underline{j}.$$
We can combine these equations into a [4-vector](4-Vectors.md) to get
$$\square(\phi,c\underline{A})=\frac{1}{c\varepsilon_{9}}(\rho c,\underline{j}).$$
In [index notation](Index%20and%20Tensor%20Notation.md) we can write D'Alembert's operator as
$$\square=\partial^\mu \partial_{\mu}$$
where
$$\partial^\mu=\frac{\partial}{\partial x_{\mu}}=\left( \frac{1}{c} \frac{\partial}{\partial t},-\underline{\nabla} \right)$$
$$\partial_{\mu}=\frac{\partial}{\partial x^\mu}=\left( \frac{1}{c} \frac{\partial}{\partial t},\underline{\nabla} \right).$$
