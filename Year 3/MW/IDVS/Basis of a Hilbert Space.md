A basis set of vectors is a complete set of elements in a vector space. It means it contains all the linear combinations and all elements in sequences. 
[[Hilbert Spaces]] are separable if a sequence $\{ \underline{g}_{n} \}$ exists with some term
$$\underline{g}_{n}=c^{1}\underline{f}_{1}+c^{2}\underline{f}_{2}+\dots+c^{n}\underline{f}_{n}\in H$$
s.t. $\underline{g}_{n}\to \underline{g}\in H$ for $n\to \infty$.
Then all the elements can be expressed as linear combination
$$\underline{g}=\sum_{i=1}^{\infty}\underline{f}_{i}e^{i}.$$
This separability means the space contains a dense countable subspace.

Hilbert spaces are separable iff they admit a countable orthonormal basis.
