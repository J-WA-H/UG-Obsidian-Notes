Take two [[Vector Spaces]] $V_{1},V_{2}$ with a [linear map](Linear%20Transforms%20and%20Symmetries.md) $L$ that relates them $L:V_{1}\to V_{2}$. For two vectors, $\underline{v}_{1},\underline{v}_{2}\in V_{1}$, $L(\alpha \underline{v}_{1}+\beta \underline{v}_{2})=\alpha L(\underline{v}_{1})+\beta L(\underline{v}_{2})$.

The map $L$ is an isomorphism if it is bijective, meaning we have a one-to-one correspondence exists so that every element $\underline{v}\in V_{1}$ has a unique element $L(\underline{v})\in V_{2}$. Each element in $V_{1}$ has a unique element in $V_{2}$.

Vector spaces which are related by an isomorphism are isomorphic.
$$V_{1}\approx V_{2}.$$
From a linear algebra perspective, isomorphic vector spaces are identical.
