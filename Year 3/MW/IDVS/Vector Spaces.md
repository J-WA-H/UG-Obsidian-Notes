A vector space $V$ over a field $E$ (e.g. $\mathbb{R}$, $\mathbb{C}$) is a set of objects $E=\{\underline{x}\}$ with certain properties:
1. Vector addition: If $\underline{x}$, $\underline{y}\in E$, then $\underline{x}+\underline{y}\in E$
2. Scalar multiplication: If $\underline{x}\in E$ and some scalar constant $\alpha$ then $\alpha \underline{x}\in E$. These scalars span the set $F=\{\alpha\}$ where normally $F=\mathbb{R}$ or $F=\mathbb{C}$.
These addition and multiplication properties imply a vector space is closed under linear operations, so vector spaces are linear spaces.

Properties of addition:
1. Commutivity: $\underline{x}+\underline{y}=\underline{y}+\underline{x}$
2. Associativity: $(\underline{x}+\underline{y})+\underline{z}=\underline{x}+(\underline{y}+\underline{z})$
3. Existence of zero vector: $\underline{0}+\underline{x}=\underline{x}$, $\underline{x},\underline{0}\in E$
4. Existence of inverse element: $\forall \underline{x}\in E$  $\exists -\underline{x}\in E$ s.t. $\underline{x}+(-\underline{x})=\underline{0}$

Properties of scalar multiplication:
1. Associativity: $\alpha(\beta \underline{x})=\beta(\alpha \underline{x})$, $\underline{x}\in E$, $\alpha,\beta\in F$
2. Existence of unity element: $1\in F$, $1\cdot \underline{x}=\underline{x}$
3. Distributivity: $\alpha \underline{x}+\beta \underline{x}=(\alpha+\beta)\underline{x}$

Examples:
1. If $E=\mathbb{C}$ and $F=\mathbb{R}$, we have the usual sum of complex numbers and multiplication by real numbers.
	This is a one complex dimensional real vector space (as field is over real numbers).
	We can also represent $\mathbb{C}$ by $\mathbb{R}^2$, $z=x+iy$, the interpretation is a space that can be represented by a 2 real dimensional real vector space.
2. $E=\mathbb{R}^n=\{x_{1},x_{2},\dots x_{n}\}$ and $F=\mathbb{R}$ with usual addition of two vectors, and multiplication is usual scalar multiplication. $E$ is an n-dimensional real vector space.
