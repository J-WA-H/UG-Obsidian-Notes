Defn: A continuous curve $\gamma$ in the complex plane is a map from $\mathbb{R}$ to $\mathbb{C}$.
$$\gamma[a.b]\subset \mathbb{R}\to\mathbb{C}.$$
$a$ - initial point
$b$ - final point

A path is a collection of points - a curve requires a parametrisation.

Defn: An open set $G$ is said to be split if $G=G_1\cup G_{2}$ s.t. $G_{1}\cap G_{2}=\phi$ where $\phi$ is the empty set.

$G$ is connected if it does not split, this is equivalent to saying that the existence of a curve $\gamma\subset G$ linking any two points in $G$. 

A set $G$ is simply connected if any two curves connecting two points can be deformed into each other without leaving $G$.
