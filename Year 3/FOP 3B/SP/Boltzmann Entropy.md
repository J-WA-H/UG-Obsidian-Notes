If we have more microstates, a system can have more ways of arranging itself.

In thermodynamics, entropy is maximised. In statistical physics, the distribution containing the most microstates is the most probable.

Boltzmann postulated that $S=S(\Omega)$, where $\Omega$ is the number of microstates.

We know that $\Omega$ is multiplicative. E.g. $\Omega_{AB}=\Omega_{A}\Omega_{B}$.
In thermodynamics, if $A$ has entropy $S_A$ and $B$ has entropy $S_B$ then the entropy of the system is $S=S_{A}+S_{B}$, so entropy is not multiplicative. We can use logs to connect multiplication and addition:
$$S\propto \ln \Omega.$$
The proportionality constant has been calculated experimentally to be Boltzmann's constant
$$S=k_{B}\ln \Omega.$$
This links entropy, a macroscopic quantity, with the number of microstates, a microscopic property.
