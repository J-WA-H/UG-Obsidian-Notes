For $\text{BaTiO}_{3}$,
![[Pasted image 20250306143328.png]]
as temperature increases, thermal displacement overwhelms the strain displacement so the [spontaneous polarisation](Ferroelectrics.md). At the [Curie temperature](Paramagnetism.md), $P_{s}=0$ which defines a paraelectric.
There is a transition from ferroelectric to paraelectric.

We can observe the order of the transition.
For a second order transition, the order parameter continuously decreases,
![[Pasted image 20250306144011.png]]
There is no latent heat in the 2nd order transition.

A first order transition is where the order parameter decrease is discontinuous,
![[Pasted image 20250306144136.png]]
This transition requires latent heat.
