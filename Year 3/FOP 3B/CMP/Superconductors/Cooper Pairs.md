Consider a perfect crystal.
![[Pasted image 20250227153519.png]]
Place an electron inside the crystal, which attracts the neighbouring nuclei creating a region with a larger positive potential.
To an outside electron, it experiences this potential which pairs with the inside electron. This is a phonon mediated electron-electron interaction. This is known as a Cooper pair.

Cooper Pairs have integer spins so are bosons.

Consider the superconductivity parameter $|\psi|^2$, this is the Cooper pair density.

As there are two electrons per Cooper pair, this can be written using the number density of [superconductive electrons](Superconductivity.md),
$$|\psi|^2=\frac{n_{S}}{2}.$$
Look at the band structure - in the ground state Cooper pairs create a [Bose-Einstein condensate](Density%20of%20States%20for%20Bosons.md).
![[Pasted image 20250227155043.png]]
The gap between the ground state and the first excited state (the first fermionic level) is of order of $\text{meV}$.
