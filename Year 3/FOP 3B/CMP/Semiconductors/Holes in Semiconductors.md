For a complete picture of a [[Semiconductor in E-Fields]], scattering needs to be considered.
Consider an electron in zero E-field with follows a random path, it ends up in the same position it started in so $\langle x \rangle=0$.
![[Pasted image 20250213123745.png]]
When an E-field is applied to the right, the electron paths are slightly shifted to the left - meaning the start and finish point no longer match so under an E-field $\langle x \rangle\neq 0$. This means electrons have a drift velocity
$$\underline{v}_{d}=-\mu \underline{E}$$
where $\mu$ is the mobility. The negative sign is because electrons are negatively charged particles.

The drift momentum is $\underline{p}=\hbar \underline{k}_{d}=m^{*}\underline{v}_{d}$, where $m^{*}$ is the [[Effective Mass]].
$$\implies \underline{k}_{d}=\frac{m^{*}\underline{v}_{d}}{\hbar}.$$
![[Pasted image 20250213124359.png]]
Due to this drift velocity, $\sum \langle \underline{k} \rangle\neq \underline{0}$, $\sum \langle \underline{v} \rangle\neq 0$ so there is a net current.

Consider a nearly full band under an E-field like the valance band at $T>0\text{ K}$.
![[Pasted image 20250213140715.png]]
As an electron is excited from the valance band to the conduction band there is an unoccupied state in the VB, so $\sum \underline{k}\neq 0$ and $\sum \underline{v}\neq 0$ so there is an instantaneous current. There is also a time averaged current when scattering is considered. 

For the full band, $\sum \underline{k}=\underline{0}$. For the RHS VB, $\sum \underline{k}=-\underline{k}_{e}=\underline{k}_{h}$, where $\underline{k}_{h}$ is the hole wavevector.
![[Pasted image 20250213141129.png]]
Holes move parallel to the E-field, so hole are positively charged pseudo particles.
For holes, $\underline{k}_{h}=-\underline{k}_{e}$, $E_{h}=-E_{e}$, $v_{g,h}=v_{g,e}$, $m^{*}_{h}=m^{*}_{e}$.
