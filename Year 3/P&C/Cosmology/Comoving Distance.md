Consider a source emitting a photon and an observer:

![[Pasted image 20250203183303.png]]

In a time interval $dt$, the photon travels a distance of $dr=cdt$.
Using the [[Cosmic Scale Factor]] the comoving distance
$$dr_{CM}=\frac{dr}{a(t)}.$$
equating the expressions for $dr$ gives
$$cdt=a(t)dr_{CM}.$$
This can be used to find an expression for the comoving distance.
$$r_{CM}(1\to 2)=\int dr_{CM}=\int_{t_{e}}^{t_{0}} \frac{cdt}{a(t)}=c\int_{a_{e}}^{a=1} \frac{da}{a\dot{a}}$$
$$=\frac{c}{H_{0}}\int_{a_{e}}^{1} \frac{da}{\sqrt{ \Omega_{R_{0}}+\Omega_{M_{0}}a+\Omega_{\Lambda_{0}}a^{4} }}.$$
Comparing with [[Lookback Time]],
$$r_{CM}(1\to 2)=\frac{c}{H_{0}}\int_{a_{1}}^{a_{2}} \frac{da}{\sqrt{ \Omega_{R_{0}}+\Omega_{M_{0}}a+\Omega_{\Lambda_{0}}a^4 }}$$
$$c(t_{2}-t_{1})=\frac{c}{H_{0}}\int_{a_{1}}^{a_{2}} \frac{da}{\sqrt{ \Omega_{R_{0}}a^{-2}+\Omega_{M_{0}}a^{-1}+\Omega_{\Lambda_{0}}a^2 }}.$$
Both depend on the density parameter but the dependence on the cosmic scale factor is different.
