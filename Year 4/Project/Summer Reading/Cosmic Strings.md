Strings arise in models where $\mathcal{M}$ is not simply connected. The topological property is disclosed if the fundamental group of $\mathcal{M}$ is non-trivial, $\pi_{1}(\mathcal{M})\neq \mathbb{I}$. The elements of $\pi_{1}(\mathcal{M})$ then classify the different types of strings. For a connected and simply connected symmetry group $G$, strings can be classified by the disconnected components of the unbroken subgroup $H$, $\pi_{0}(H)$. The breaking of the local $U(1)$ symmetry in the abelian Higgs model admits string solutions since field configurations on a closed loop in physical space can similarly correspond to non-trivial windings about the degenerate circle of minima in $V(\phi)$. In the Lorenz gauge, $\partial_{\mu}A^{\mu}=0$, the Higgs field takes the same form as the global string at large distances of the core,
$$\phi=\eta e^{ in\theta },\tag{7.1} $$
where $n$ us an integer, the string winding number. The gauge field asymptotically approaches$$A_{\mu}\approx \frac{1}{ie}\partial_{\mu}\ln \phi.\tag{7.2} $$With the asymptotic forms, we have $\mathcal{D}_{\mu}\phi \approx 0$ and $F_{\mu \nu}=0$ far from the string core. The lowest energy string configuration has a winding number $n=\pm 1$. The length of the string is determined by the Compton wave length of the Higgs and gauge bosons. When the gauge bosons are heavier than the Higgs, the string has an inner core of false vacuum and a magnetic flux tube outside. The total string mass per unit length is
$$\mu \sim \eta^2.\tag{7.3} $$
For GUT scale strings with $\eta \sim 10^{16}\text{ GeV}$, this corresponds to a mass density of $\mu\sim 10^{22}\text{ g cm}^{-1}$, the internal structure of the string becomes unimportant and physical quantities of interest, such as the energy-momentum tensor $T^{\mu}_{\;\;\nu}$ can be averaged over the string cross-section. For a straight string lying along the z-axis we can get the effective energy-momentum tensor
$$\tilde{T}^{\nu}_{\;\;\mu}=\delta(x)\delta(y)\int T^{\nu}_{\;\;\mu}dxdx.\tag{7.4} $$
Given that the string is Lorentz invariant along the z-axis, we have $\tilde{T}^{0}_{\;\;0}=\tilde{T}^{3}_{\;\;3}$ and all other components vanishing. This gives
$$\tilde{T}^{\mu}_{\;\;\nu}=\mu\delta(x)\delta(y)\text{diag}(1,0,0,1).\tag{7.5} $$
This string has a large tension so the curved static segments will contract and rapidly acquire relativistic speeds.

For the global $U(1)$ string there is no gauge field to compensate the variation of the phase at large distances so the energy per unit length is divergent. For the $n=1$ string we have
$$\mu \approx 2\pi \eta^2\ln\left( \frac{R}{\delta} \right)\tag{7.6} $$where $\delta$ is the core width and $R$ is a cut-off radius that must be imposed at some large distance. Depending on the situation, this cut-off will be provided by the curvature radius of the string or by the distance to the nearest string in the network. The logarithmic term is a coupling to the Goldstone boson field in the model and implies long range interactions between strings with force $F\sim \frac{\eta^2}{R}$. 

Other strings, such as the $Z_{N}$ strings, are encountered in phase transitions after which a discrete symmetry remains intact. For $N>2$, $Z_{N}$ strings can form networks with vertices from which several strings emanate.

Strings can trap charge carriers that could either be bosonic or fermionic, and would make the string superconducting. In contrast to normal strings which has subtle gravitational effects, the electromagnetic interactions of superconducting strings can enrich the observable phenomena.
